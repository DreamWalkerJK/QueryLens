# 桌面 UI 冒烟记录

目标环境：Windows x64、.NET SDK 10.0.102、Avalonia 12.1.2。记录日期：2026-09-13。

## 自动启动冒烟

使用 Release framework-dependent 发布目录启动 `publish/win-x64/QueryLens.Desktop.exe`，脚本等待窗口进入空闲状态并读取进程窗口属性：

| 检查 | 结果 |
|---|---|
| `WaitForInputIdle` | `True` |
| 窗口标题 | `QueryLens · 数据库慢查询诊断` |
| 原生窗口句柄 | 非零（已创建） |
| `Responding` | `True` |
| 进程存活 | 启动后约 1.2 秒仍为 `True` |
| 启动后清理 | 冒烟脚本主动结束进程，未留下后台实例 |

启动期间会初始化用户目录下的 SQLite 工作区，并加载离线样例（若当前模式为空）。应用随后由脚本关闭；该检查不访问用户现有数据库。

## 交互路径覆盖

下列控件已绑定到实际异步命令，并在 Release 构建中通过 Avalonia XAML 编译：

| 区域 | 验证内容 |
|---|---|
| 连接与能力 | 保存、测试、复制、确认删除、加载离线样例 |
| 慢查询与指纹 | 原生文件选择器（`.log`/`.txt`/`.json`）、导入、在线采集 |
| 执行计划与诊断 | 原生文件选择器（`.json`/`.xml`）、导入、选择、基线、比较 |
| 采集任务与设置 | 原生保存文件选择器（`.json`）、脱敏导出、四类取消命令、刷新 |

文件选择器通过窗口 `StorageProvider` 获取本地路径，用户取消选择时保持原路径不变。导出选择器开启覆盖提示，并建议 `QueryLens-report.json` 文件名。

## 待人工点击的一步

原生文件选择器由 Windows Shell 提供，自动化启动检查不会代替人工点击。发布版本验收时应在 Windows 桌面依次点击“浏览…”和“导出”按钮，确认对话框可打开、取消不会改变路径、选定文件会回填路径，然后执行对应导入/导出命令。该步骤不涉及网络连接或数据库写入。
