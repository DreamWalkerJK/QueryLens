# 桌面 UI 冒烟记录

目标环境：Windows x64、.NET SDK 10.0.102、Avalonia 12.1.2。记录日期：2026-09-14。

## 自动启动冒烟

使用 Release framework-dependent 发布目录启动 `publish/win-x64/QueryLens.Desktop.exe`，脚本等待窗口进入空闲状态并读取进程窗口属性：

| 检查 | 结果 |
|---|---|
| `WaitForInputIdle` | `True` |
| 窗口标题 | `QueryLens · 数据库慢查询诊断` |
| 原生窗口句柄 | 非零（已创建） |
| `Responding` | `True` |
| 进程存活 | 启动后约 1.2 秒仍为 `True` |
| 启动后清理 | 冒烟脚本主动结束进程，未留下后台实例 |

启动期间会初始化用户目录下的 SQLite 工作区，并加载离线样例（若当前模式为空）。应用随后由脚本关闭；该检查不访问用户现有数据库。

## 交互路径覆盖

下列控件已绑定到实际异步命令，并在 Release 构建中通过 Avalonia XAML 编译：

| 区域 | 验证内容 |
|---|---|
| 连接与能力 | 保存、测试、复制、确认删除、加载离线样例 |
| 慢查询与指纹 | 原生文件选择器（`.log`/`.txt`/`.json`）、导入、在线采集 |
| 执行计划与诊断 | 原生文件选择器（`.json`/`.xml`）、导入、选择、基线、比较 |
| 采集任务与设置 | 原生保存文件选择器（`.json`）、脱敏导出、四类取消命令、刷新 |

文件选择器通过窗口 `StorageProvider` 获取本地路径，用户取消选择时保持原路径不变。导出选择器开启覆盖提示，并建议 `QueryLens-report.json` 文件名。

## 实际桌面验收

使用 `publish/win-x64/QueryLens.Desktop.exe` 在 Windows 桌面实际启动并读取窗口无障碍树，窗口标题为 `QueryLens · 数据库慢查询诊断`，进程正常响应。

| 操作 | 实际结果 |
|---|---|
| 切换“慢查询与指纹” | 显示离线 PostgreSQL 聚合行、SQL 明细、关键词/起始时间/数据库/指纹筛选框；提示“P95/P99：不可用（无原始样本或直方图）”。 |
| 切换“执行计划与诊断” | 显示两个同指纹计划，其中一个标记基线；TreeView 展开 `Sort` 节点后显示估算行数、实际行数不可用和成本；节点详情保留来源、版本、JSON import 方法和采集时间；诊断建议显示排序开销和 Seq Scan。 |
| 切换“采集任务与设置” | 显示脱敏报告路径、原始 SQL 显式选项、导出按钮、保留天数、四类取消按钮、刷新按钮和错误记录区域。 |
| 点击报告“浏览…” | Windows Shell 对话框“选择脱敏报告保存位置”成功打开，默认文件名为 `QueryLens-report.json`；点击“取消”后返回应用，原路径未改变。 |

本次只打开并取消文件选择器，没有选择、删除、覆盖文件，也没有连接或写入真实数据库。
