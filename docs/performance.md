# 性能记录

本记录用于给出可复现的基线，不把小样例运行时间外推为生产吞吐量。

## 测试环境

- 日期：2026-09-13
- 平台：Windows x64，.NET SDK 10.0.102，Release，单进程、单线程（并发度 1）
- 输入：PostgreSQL `samples/postgres-plan.json`（3 个计划节点）；SQL 模板 10,000 条，仅替换数字字面量
- 工具：临时 `tmpapp/PerfProbe2` 控制台探针，直接调用 `QueryLens.Core` 的 `SqlFingerprinter` 和 `PlanParser`

## 结果

| 项目 | 结果 |
|---|---:|
| 指纹输入数量 | 10,000 条 |
| 计划解析次数 | 1,000 份 |
| 单份计划节点数 | 3 |
| 指纹化耗时 | 106.8 ms |
| 计划解析耗时 | 37.7 ms |
| 进程 CPU 时间 | 156.2 ms |
| 托管堆读数（探针结束时） | 11,749,112 bytes |
| 并发度 | 1 |
| 准确性 | 10,000 条字面量变化得到 1 个规范指纹；1,000 份计划均成功解析 |

这些数据是本机基线，受 CPU、SDK 和运行时状态影响。尚未代表多线程、超大 SQL、超大计划或生产数据库网络采集性能；后续若引入批量或并发优化，应在相同输入规模下重新记录。
